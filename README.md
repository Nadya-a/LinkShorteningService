# Link Shortening Service

## Как создавался и как работает сервис

Задание было на создание консольного сервиса, который сокращает ссылки и позволяет ограничить количество переходов по ним. По заданию у ссылки должен быть срок действия, у пользователя свой UUID, чтобы можно было связать созданные ссылки с конкретным пользователем.

Для начала было определено, какие данные нужны для работы сервиса: у каждой ссылки есть такие поля, как исходный адрес, короткий адрес, UUID создателя, оставшееся количество переходов и дата окончания действия. Всё это собрано в классе `ShortLink`.

Код разделён на четыре класса:

- `Main` отвечает за консольное меню, принимает ввод пользователя и обрабатывает выбранное действие
- `ShortLink` создан для создания объектов ссылки, определения её срока действия и проверки ограничений
- `ShortLinkGenerator` генерирует набор символов, которые потом идут в короткий адрес
- `LinkService` работает с файлами, сохраняет ссылки и получает UUID пользователя

### Создание короткой ссылки

Пользователь вводит в консоль длинную ссылку и указывает лимит переходов по ней. После этого программа с помощью `SecureRandom` задаёт короткий адрес: к префиксу `clck.ru/` добавляется сгенерированный код из цифр и букв.

После этого, если пользователь вводит в консоль короткую ссылку, программа находит запись с совпадающим значением короткой ссылки и берёт из этой записи длинную ссылку, по которой и редиректит пользователя.

Перед сохранением объекта `ShortLink` в файл программа проверяет, есть ли уже такой исходный адрес (т.е. запись с такой же длинной ссылкой) у пользователя с таким же UUID. Если есть, повторная запись не создается и в консоль выводится «Такая ссылка уже есть в файле!». Если UUID пользователя другой, тот же исходный адрес можно сохранить ещё раз с новой короткой ссылкой.

### Как определяется пользователь

В этом консольном сервисе нет авторизации, определение юзера происходит через отдельно хранящийся идентификатор пользователя. При первом добавлении ссылки программа проверяет файл `uuid.txt`, и если он пустой, то генерируется UUID и записывается в этот файл.

При последующих запусках используется этот, уже сохранённый UUID. И этот же идентификатор записывается в данные каждой созданной пользователем ссылки.

### Как сохраняются данные

Для хранения данных о ссылках в проекте использовалась библиотека Gson. Все ссылки хранятся в JSON файле `links.json`, и при создании каждой новой ссылки или изменении уже существующей (например, при подсчете кол-ва переходов по ссылке) все изменения сохраняются в этот же файл. За счёт этого данные не удаляются после закрытия программы, а остаются в файле.

### Как работает лимит переходов

Лимит пользователь задаёт сам при создании ссылки. Перед открытием страницы лимит уменьшается на единицу, и измененное значение сохраняется в файл. Если лимит становится равен 0, программа блокирует дальнейшие переходы и выводит сообщение «Лимит переходов по ссылке истек».

Также есть обработка некорректного ввода лимита: если оставить поле пустым, ввести в него текст/ноль/отрицательное число — программа установит лимит по умолчанию, равный 3.

### Как работает срок действия ссылки

Срок жизни ссылки задается в коде автоматически: при создании ссылки к текущей дате прибавляется три дня.

Истечение срока жизни ссылки проверяется при переходе по короткой ссылке. Если дата истечения уже прошла, программа выводит в консоль «Ссылка просрочена» и удаляет запись из `links.json`.

### Как открывается исходная страница

Если ссылка доступна, программа выполняет все необходимые проверки на лимит и дату истечения, и если ссылка еще работает, то вызывает метод `Desktop.getDesktop().browse(...)`, который передаёт исходный адрес браузеру по умолчанию.

## Инструкция для пользователя

### 1. Запуск программы

Для работы с проектом необходимо скачать его из репозитория на GitHub — https://github.com/Nadya-a/LinkShorteningService.git — и открыть его в IntelliJ IDEA.

Для запуска программы надо запустить метод `main()` в классе `Main`. В репозитории уже есть `uuid.txt` и `links.json`, где есть пример сгенерированных программой данных.

Если необходимо начать с новым UUID и пустым списком ссылок, перед первым запуском эти файлы нужно очистить.

После запуска в консоли появится меню:

1. Добавить новую ссылку
2. Перейти по короткой ссылке
0. Выход
Введите номер действия, которое хотите совершить:

Чтобы выбрать действие, нужно ввести его номер и нажать на Enter.

### 2. Создание короткой ссылки

Введите в консоль `1` и введите длинную ссылку, которую нужно сократить.

Укажите максимальное количество переходов. Если в поле ничего не ввести или ввести некорректный набор символов, по умолчанию установится лимит в 3 перехода.

После этого программа создаст короткую ссылку вида `clck.ru/abc12345`.

### 3. Переход по короткой ссылке

Введите в консоль `2` и введите короткую ссылку вида `clck.ru/abc12345` целиком.

Если ссылка рабочая и лимит переходов не закончился, нужная страница автоматически откроется в браузере. В случае, если ссылка некорректна, просрочена или лимит переходов истек, программа выведет сообщение об ошибке в консоль.

### 4. Завершение работы

Чтобы выйти из программы, введите в консоль `0` на этапе главного меню.
